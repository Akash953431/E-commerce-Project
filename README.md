# ShopEase - E-commerce Project

A beginner-friendly, responsive e-commerce storefront built using **HTML, CSS, and vanilla JavaScript**.

## Features

- Responsive homepage and product grid
- Product search by name
- Category filtering
- Add products to the shopping cart
- Increase and decrease product quantities
- Remove products from the cart
- Automatic cart count and total price calculation
- Demo checkout message (no real payment processing)

## Project structure

```
E-commerce-Project/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Run the project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the Live Server extension.
4. Search for products, choose a category, and try the cart.

## Technologies

- HTML5 - page structure
- CSS3 - layout, styling, and responsive design
- JavaScript - product display, search, filtering, and cart logic

## Note

This is an educational front-end demo. It does not include a backend, user accounts, database, order storage, or real payment gateway.
